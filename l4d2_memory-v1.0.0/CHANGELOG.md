# 更新记录

## v1.0.0 — 2026-10-19

- 作者署名：MMFelix。
- 提供 Windows 外部只读玩家状态采集与 DGHub SDK v1 桥接。
- 保留受伤、倒地、挂边、五种特感控制、死亡和脱离控制，共 10 项反馈。
- 移除黑白、被扶起、回血和复活的反馈与配置项。
- 倒地可持续反馈，扶起或死亡后停止续播，最后一段最长 0.5 秒。
- 同一玩家的死亡事件优先于时钟回退处理，避免遗漏死亡波形。
- 提供动态、固定和挑战三种强度模式，独立配置事件波形、通道、时长和最低强度。
- 采用常驻采集线程、重复状态去重、低频等待和状态上报节流。
- 提供版本指纹检查、离线配置预览、诊断工具、自动测试和可复现打包脚本。
